# Security Policy

MailKeys has Accessibility permission and an event tap on Apple Mail, so security and privacy reports matter a lot.

## Reporting a vulnerability

Please **don't** open a public issue. Report it privately through GitHub instead: go to the repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and what an attacker could do with it. You'll get a reply as soon as possible, and credit in the release notes if you'd like it.

## What counts

Anything that breaks the promises in the README, for example:

- MailKeys acting on keys outside Apple Mail, or swallowing typing it shouldn't
- Keystrokes, message contents or account data being recorded, stored or sent anywhere
- Another app abusing MailKeys' Accessibility permission

## Supported versions

Security fixes go into the latest release.
